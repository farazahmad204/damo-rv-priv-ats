# SpacemiT K3 Pico-ITX (SpacemiT X100)

Runs the suites on real hardware, without a simulator. The test ELF is sent
over the UART to a minimal M-mode runner that replaces OpenSBI in the board's
boot chain ([ACT-Runner](https://github.com/farazahmad204/ACT-Runner-for-Vision-Five-2-RISC-V-Board-),
board `spacemit_k3_pico_itx`). The runner loads the ELF and starts it in M-mode
on **hart 0**. The K3 has no monitor hart polling `tohost`: `RVMODEL_HALT_PASS`
and `RVMODEL_HALT_FAIL` write `tohost` (1 or 3), restore the runner's `mtvec`
(saved by `common/entry.S` in `rvtest_entry_mtvec`) and `ecall` into the runner,
which ends the case.

```bash
cd Hypervisor_CSR
make clean && make CONFIG=spacemit-k3-pico-itx CROSS_COMPILER=/path/to/riscv64-unknown-elf-
```

| Item | Value | Source |
|---|---|---|
| Load window | `0x110000000`-`0x130000000` (`MEM_BASE=0x110000000`) | runner payload window |
| Boot hart | 0 (`RVMODEL_BOOT_HARTID`) | runner starts ELFs on hart 0 |
| UART0 | `0xD4017000`, 8250 (XScale/PXA), register shift 2, byte accesses, 115200 baud set by the boot loader | runner board config |
| CLINT | MSIP `0xF1810000`, MTIMECMP `0xF1814000`, mtime `0xF181BFF8` (hart 0) | runner board config |
| `misa.H` | set in `RVMODEL_BOOT` (resets to 0 on the X100) | ACT K3 configuration |

## UART

The boot loader leaves UART0 configured and the runner prints through it. On
this XScale-style UART, `IER` bit 6 (UUE) enables the unit, so the standard
`uart_init()` (which writes `IER = 0`) would switch it off.
`PLATFORM_UART_KEEP_FIRMWARE_SETUP` makes `uart_init()` keep the firmware's
setup; the suites only transmit.

## Extensions

`rvtest_config.h` is generated by riscv-unified-db (`udb-gen cfg-c-header`) from
`spacemit-k3-pico-itx.yaml`, the ACT configuration for this board with H
(`farazahmad204/riscv-arch-test`, branch `megrez-hypervisor-sail015`). The X100
implements H 1.0, Sstc and the privileged 1.12+ CSRs, so no absent-CSR
emulation is needed. It does not implement Smstateen, so `Sha` stops at
`mstateen0`.

All 23 suites of the Megrez default list build for this config; they have not
run on the board yet.
